# Security policy

## Supported version

Security fixes target the latest code on the default branch. The current
0.9.x builds are beta software and are not code-signed release artifacts.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not
open a public issue with exploit details, user data, original photographs,
database files, signing material or access tokens.

Chromik processes photographs locally. A security report should use synthetic
or redistributable fixtures whenever possible.
