# Chromik 珂影 0.9.3 Beta

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Chromik 珂影是一个完全本地运行的胶片数字化与非破坏处理桌面应用，采用独立实现的色彩与工作流代码。

## 这一版能做什么

- 先创建“胶卷”，再向胶卷内添加长条多张、印样多张、单张或未分类原始素材。
- 每卷同时保留“原始文件”和“处理后画面”两个视图；原始文件始终只读，分帧和调整用 SQLite 参数保存。
- 胶卷项目旁直接提供删除；胶卷右键菜单支持编辑、导出和删除。素材/画面支持删除确认，图库支持 `Command/Ctrl/Shift` 多选、全选和批量移除。移除只清理 Chromik 记录与缓存，不删除磁盘原图。
- 胶卷信息可编辑：片种、型号、ISO、相机、镜头、冲洗参数、拍摄日期和备注。
- 主工作流按“图库 → 胶片校准 → 分帧 → 调整照片 → 导出”排列：胶片校准按整卷保存片种、片基与去色罩/反相参数，之后新建和已有画面都会继承；裁切始终作为单张几何操作独立存在。
- 本地 OCR 读取上/下/左/右片基文字，自动匹配常见 Kodak、Fujifilm、Ilford 型号、片种和 ISO；可先选中一个原始素材再识别。
- 导入后可通过片框亮度、底色和通道色差自动判断彩色负片、彩色反转片、黑白负片和黑白反转片，并保留手动更正。
- 非破坏手动分帧：自动网格建议、连续拖拽新建、Shift 多选、整体移动、四角校正、角点放大镜、明显的删除入口与连续帧号。
- 修改照片预览支持 Mac/Windows 精准触控板双指移动与捏合缩放、中键拖动、空格加左键拖动、适合窗口、100% 和缩放快捷键；旋转手势被禁用。
- 预览重建、直方图、RGB 波形、自动范围和自动转换在独立 Worker 执行；滑块输入按屏幕帧率合并，拖动时使用 720px 交互代理并实时显示结果，松手后自动恢复完整代理质量；相同几何结果会缓存复用。
- Photoshop 风格画布裁切（拖动裁切框、边线和控制点）、自动画面范围、四角透视、任意角度拉直、镜头畸变、90° 旋转、水平/垂直翻转、完整原始素材片基取样、分通道密度转换。
- 色彩核心使用 `chromik-6`：图库显示图、16 位线性开发代理和主文件有明确角色；片基分析、自动范围、编辑预览、直方图、处理后缩略图与导出共享同一 Float32 处理图。未经测量的通道矩阵默认关闭；曝光与调色只在密度归一化为正像之后执行。负片默认使用 Chromik 自研的平滑趾部/肩部显示曲线，不以隐藏曝光增益抬亮画面。
- 曝光、色温、色调、对比度、高光、阴影、Gamma、饱和度、自然饱和度、高光过渡、褪色、Printer Lights、黑白模式及 RGB/单通道曲线均可调整。
- 内置自然、暖调相纸、经典彩色、清透反转和银盐黑白五种独立实现风格，并可调整风格强度；点击曲线添加锚点，选中后按 Delete 或双击删除。
- 60 步撤销/重做；配方同步到同卷时保留每一帧自己的分帧四角，不会把画面范围覆盖掉。
- 高像素翻拍输入：支持手机常用 HEIC/HEIF、JPEG/PNG/TIFF，以及 DNG、ARW、CR2/CR3、NEF、RAF、RW2、FFF 等常见相机 RAW。HEIC 和 RAW 均在独立线程本地解码；RAW 生成 16 位本地缓存，磁盘原始文件仍只读保留。单张代理最长边 4096px，长条代理 8192px；源图限制提高到 10 亿像素。
- JPEG/PNG/TIFF 后台安全导出，支持单张、所选画面、整卷和多卷范围，调整后预览、保留原分辨率、链接宽高、锐化和冲突策略；PNG/TIFF 可选真实 16-bit，输出可选嵌入 sRGB 或 Display P3 ICC 配置文件。
- 导出预览支持双指移动、捏合/滚轮缩放、中键或空格拖动、100% 与适合窗口；待导出画面使用不会挤压文字的缩略卡片多选。
- 接触印样可单独导出，提供经典、暗房、极简三种风格，3–6 列、标题、文件名/胶卷信息开关以及 JPEG/PNG。
- macOS 使用隐藏标题栏，顶部自绘区域可拖动，并为左上角红绿灯预留安全空间。
- 全部界面文字使用随应用打包的 HarmonyOS Sans SC，并在设置中提供版本、处理方式和隐私说明的“关于 Chromik 珂影”。

## 运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

生产构建后运行：

```bash
npm run build
npm start
```

测试：

```bash
npm test
```

提交前完整验证：

```bash
npm run verify
```

QA 故障注入验收（开发代理缓存截断/改坏/删除 → 校验和自愈重建，QA-06）：

```bash
npm run qa:fault-inject
```

QA-06 全量韧性验收（1000 帧、磁盘写满、原图丢失/重定位、备份回滚、进程中断恢复及缓存自愈）：

```bash
npm run qa:resilience
```

Windows x64 打包配置已放入 `package.json`：

```bash
npm run dist:win
```

## 快捷操作

- 图库：单击单选；按住 `Command/Ctrl/Shift` 点击切换多选；双击原始素材进入分帧；双击处理后画面进入修改照片。
- 分帧：滚轮缩放；中键拖动画布；Shift 多选；拖框体移动；拖四角时显示放大镜；“添加帧”会保持连续添加，完成后点“选择”或按 `Esc`；`Delete/Backspace` 删除选中帧。
- 修改照片：触控板双指移动、捏合缩放；中键拖动或空格加左键拖动；`Ctrl/Cmd+0` 适合窗口；`Ctrl/Cmd+1` 100%；`Ctrl/Cmd++/-` 缩放。

## 胶片校准取样

- 最可靠的识别框应包含照片内容和少量干净、未曝光的橙色片基；只框照片内容会失去去色罩的 D-min 参考。
- 不要把大面积白色灯箱、手指、夹具、强漏光或严重污染区域框进来。
- 齿孔不是片基样本。自动统计会排除其高亮像素，但手动框选时尽量避开完整的一排齿孔。
- 识别框只决定片基与密度统计范围，不会裁切照片，也不会改变后续几何。

## 当前边界

- RAW 使用随应用打包的 LibRaw WASM 解码器；不同相机的新型号或私有压缩可能仍需随 LibRaw 版本更新。当前没有可随仓库分发的真实 RAW 样片，因此构建链已验证，但仍应使用用户相机文件做兼容性验收。
- 自动分帧目前是按素材类型、比例和张数生成的可编辑几何建议，不是训练模型驱动的画框检测；复杂重叠印样需要手动校正。
- 片基 OCR 依赖边缘文字清晰可见；它能识别胶卷型号/ISO/片种，相机和镜头通常不写在片基上，仍需手动填写。
- 当前负片转换包含线性化、稳健共址片基估算、联合密度锚点、分区交叉色偏保护和自研柔和层次曲线，但不宣称 Status M、扫描器/相机光谱标定或复刻其他软件的色彩模型。输入设备配置均有版本号且明确标为通用配置；真正的逐相机、逐灯箱与逐胶卷实测光谱/ICC 配置仍是进一步提高颜色准确度的关键。
- 灰尘/划痕自动修复、线性 DNG 和 HDR 多曝光合成属于实验功能；红外通道除尘尚未加入。
- Windows 构建配置已准备，但本轮在 macOS 上开发，尚未声称完成 Windows 真机安装、升级和卸载验证。

## 目录

```text
src/main       Electron 生命周期、IPC、自定义媒体协议、SQLite、片基 OCR
src/preload    受限业务 API
src/renderer   React 图库、分帧器、修改照片和导出界面
src/core       共享色彩、密度估算、几何变换、直方图与 RGB 波形
src/adapters   HEIC 解码、16-bit PNG 编码等文件适配
src/workers    HEIC 解码、预览和全尺寸后台导出
src/shared     配方、胶卷、素材与 IPC 数据类型
```
